# Dusk — original photo pad kit

16 synthesized one-shots, created specifically for this project with
`scripts/make-dusk-kit.py`. No artist recordings, third-party samples, voices,
or downloaded sound packs are used. Acoustic-like labels describe synthesized
textures rather than recordings of those instruments.

Mono 16-bit PCM WAV, 32 kHz. Pitched material uses D minor. No added delay.
The generation script is deterministic and uses only Python's standard library.

Rows: chords/pluck; pluck/air/reverse/texture; bass; drums/percussion.
Files are bundled with the app and decoded before live performance.
